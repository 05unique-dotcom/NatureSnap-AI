# Security

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Report it privately through the repository's GitHub security advisories feature or contact the maintainers through a private GitHub channel.

Include:

- A clear description of the issue
- Steps to reproduce or a proof of concept
- The affected file or endpoint
- Any suggested mitigation

Do not include API keys, personal data, or other secrets in the report.

Please allow maintainers reasonable time to investigate before publicly disclosing the issue.
